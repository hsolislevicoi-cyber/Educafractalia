Nota metodológica. Los puntajes Likert (rango bruto 3–9 por dimensión) se normalizan a escala 1–4 mediante la fórmula N = 1 + 0.5·(suma − 3). El ítem "Las matemáticas son difíciles para mí" se puntúa invertido. Sistema de Creencias se calcula únicamente con Likert (sin preguntas abiertas), por decisión metodológica fundada.

Cómo se calcula. Cada dimensión es el promedio entre el Likert normalizado (1–4) y las preguntas abiertas evaluadas (Recursos: P1–P2 · Heurísticas: P3a–P3b · Control: P4–P5). Sistema de Creencias usa solo el Likert. Niveles: Destacado ≥ 3,40 · Competente 2,65–3,39 · Adecuado 2,00–2,64 · Insuficiente < 2,00. Los casos en zona de transición (2,55–2,65) o a ±0,01 de un umbral se marcan para revisión docente: la clasificación orienta, no etiqueta.
